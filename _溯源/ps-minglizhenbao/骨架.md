# 《命理珍宝》（香港版）骨架

> 作者：段建业，癸未年仲冬（2003 年冬）作。师承盲师郝金阳，属**盲派**体系。
> 本骨架服务于 **补差任务 E4**：只提取香港版相对内地版《命理珍宝》的独有内容。

## 一句话主旨

八字先看**原象**——干支配置、宾主位置、十神意向、虚实贼捕、八字之势——原象定了吉凶与层次，
大运管吉凶、流年管应期；**抛弃日主衰旺与扶抑用神**，靠"揣摩十干人性"与"象"来断命。

## 作者的核心命理主张

1. **弃衰旺、弃扶抑用神。** 日主强弱"在命里没有任何实际意义"，既不表示身体好坏，也不表示能力
   强弱；找用神只是初学者的拐杖。（ch23、ch27 明确主张）
2. **吉凶与应期分论。** 八字看贵贱，大运看吉凶，流年看应期；流年本身不主喜忌，
   用神流年受制反凶，忌神流年受克反吉。（ch1、ch12）
3. **"有"与"没有"论。** 命理本质是描述各要素的状态，不是缺啥补啥。病神旺现入主且有生 →
   该事物不好；病神弱现入宾或被去 → 反得此神。（ch18）
4. **贼神捕神。** 忌神如"贼"，用神如"捕"；捕神旺喜贼神出现，局中捕运见贼、运中贼临流年捕到，
   皆应吉；有捕无贼反凶。（ch19）
5. **活论十神与六亲。** 财可为父、官印亦可为父；伤官与杀都可是子。六亲类象多样，不可死看。（ch1、ch35、ch41）
6. **看"势"。** 伟人出色之人八字都有势，有势后看病神在哪；"得势的八字，病神是什么就可以得到什么"。（ch21）
7. **调候有严格条件，且调候不怕刑冲破害**——调候是季节、是时间，属无形，不可与被坏的有形五行混谈。（ch14）

## 作者的断法风格

- **流派倾向**：盲派（师承郝金阳），明确的**反旺衰派、反新派**，也批邵伟华。
- **推理路径偏好**：原局取象（干支配置 + 宾主位置 + 十神意向 + 虚实贼捕）→ 判吉凶层次 → 大运定吉凶 →
  流年定应期；**完全不从月令取格、不取扶抑用神**。
- **命例使用习惯**：理论为主、命例密集佐证（名人造 + 师门造 + 学员造并重）；命例多"已知结果倒推象"。
- **口吻**：强论战性，大量直接点名批评流行理论（新派、邵氏），并反复强调"歪理 / 正解"之分。

## 盲点与边界

### 时代与流派局限

1. 时代是 2000 年前后，命例语境集中于"官员级别（处级/厅级/一品）""军阀混战""下海经商/下岗"，
   对互联网、自由职业、跨境等现代业态几乎无覆盖。断"官级"用的是旧制中文官阶，直接套现代会有偏差。
2. 盲派与子平格局派、旺衰派、调候派结论大面积相反。"伤官见官"在此派是吉（去官得官），
   在子平一律论凶；"取用神"在此派根本不取。**两边混用会互相打架。**
3. 女命章节（40 绊禄桃花、33 色与性）带有明显旧时代贞操语境。按任务卡要求，
   旧语境断语（贞操歧视 / 职业贵贱）**一律降级不采用**；实质的婚姻不顺内容用中性语言表述。

### 未被证明的假设

4. 作者反复宣称"命理是唯一能完整算准人生的最可靠方法""准不准是水平问题"，这是信念而非可检验命题。
5. 大量结论是"已知结果倒推象"（船王、朱元璋、名人造），这套符号系统只能自证内部一致，
   不能自证预测力。
6. "一个时辰之差命运完全不同"的强决定论，与作者同时承认的"同辰不同命"（ch18 岳飞思考题、
   ch32 同辰三例）之间存在张力，作者用"类象相同"化解，缺少可判定的边界。

### 方法的失效场景

7. **一象多义时没有判据。** 同一个"戌"可为色情场所、可为庙、可为烘干炉、可为库；
   ch33 明确出现"同是乙庚合，为何招牌没倒"的自我质疑而未给判据。取象高度依赖经验与师承。
8. **并非所有八字都能找到"用神/忌神"。** 作者自己承认"有些八字怎么看都不好"（ch47 泼妇造），
   此时断法只能给"差命"而不能给层次刻度。
9. **本书无系统疾病断法**，仅在个别命例中顺带提及，不能用于"问身体哪里有病"的咨询。
10. **缺少量化刻度。** "富过千万""几十万""资产千万/亿"是命例自带的已知数，不是从八字推出的可计量模型。

### 最强的反驳

11. 最有力的反驳是：作者用同一批"已知结果"的命例事后取象，凡是解释不通的（徐先生职业反复、
    阎锡山时辰改判）就以"记忆差""书中所记有误"带过；而反对者用同样的手法也能给任何八字
    编出自洽的象。作者在 ch32 已认识到"命学看不见摸不着，极难反驳"，但自己的反驳手段只是"找反例"，
    并未建立可证伪的判据。

### 与其他流派的冲突点

12. 与**新派（衰旺取用）**：直接对立，作者专章批判（ch1、ch11、ch27）。
13. 与**邵氏（太岁/岁运并临/天克地冲论凶）**：正面对立（ch12、ch27）。
14. 与**子平格局派**：本书不取月令格局，但借用"格"名（伤官去官格、杀刃格、官禄格）而重定义。
15. 与**调候派（穷通宝鉴）**：借用"调候"之名，但重定义其适用条件，并主张"调候不怕被坏"，
    与穷通"调候被破则凶"不同。
