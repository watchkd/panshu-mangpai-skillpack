# 四柱八字模型模板

> 本模型分两层：L1-L3 是**所有命理书共享的不可变底层**（四柱、十神、五行）。
> L4-L8 是**从书中生长出来的技法层**——由第 2 步骨架根据本书的实际章节目录和内容结构生成，
> 不从预设模板中套用。不同书会长出不同的 L4-L8。
>
> 模型路径写法：`L1四柱 > 日柱 > 地支 > L2十神 > 正官 > L8断事 > 婚姻`

## L1 · 四柱 [不可变底层]

每柱的标准展开维度：

```
年柱 / 月柱 / 日柱 / 时柱
  ├── 天干  [五行] [阴阳] [ <- L2十神 ]
  ├── 地支  [五行] [阴阳] [ <- L2十神 ]
  ├── 藏干  [主气/中气/余气] [五行] [ <- L2十神 ] [透出与否]
  ├── 纳音  [纳音五行]
  ├── 空亡  [旬空] [空亡对十神的影响]
  └── 十二长生  [该柱天干在地支的十二长生状态]
```

## L3 · 五行体系 [不可变底层]

### 五行生克

```
    生：木 → 火 → 土 → 金 → 水 → 木（循环）
    克：木 → 土 → 水 → 火 → 金 → 木（循环）
```

### 旺衰判断维度

提取规则时，凡涉及旺衰判断的，标注用的哪个维度：

```
旺衰判断维度
├── 得令（月支是否生扶日干）
│   └── 月令五行 ↔ 日干五行的生克关系
├── 得地（日干在地支的通根情况）
│   └── 藏干中有无与日干同五行者
├── 得生（天干中有无生扶日干者）
│   └── 印星是否透出有力
├── 得助（天干中有无比劫帮扶）
│   └── 比肩劫财是否透出
└── 综合：身强 / 身弱 / 中和 → 决定取用方向
```
