### C-B1-001 例一 · 坤造（比肩争夫，偏房转正室）
- 八字：坤造 辛酉 / 丁酉 / 丙申 / 壬辰（8岁起运，89戊辰、99己巳为流年；出生地：未载）
- 出处：盲派命理经典 · 整理者自序「试举几例」例一
- 涉及规则：
  1. [L8断事 > 婚姻 > 妾命填房二婚] 「比肩争夫，偏房宠妾」——丁（劫财，比劫）与壬（官星）天干相合，为争夫之象
  2. [L3五行体系 > 干支相互作用 > 冲合刑害表] 丁酉/壬辰「天合地合」（丁壬合、酉辰合）→ 夫妻正配之象
  3. [L3五行体系 > 地支三合] 申辰拱水、壬代子水，申子辰三合水局 → 对丙日主为「正官局」
  4. [L2十神体系 > 食神 > 六亲] 女命以食神为女，辰中戊（丙日主之食神）为女儿
- 推理链：
  1. 诀云「比肩争夫，偏房宠妾」：月干丁（劫财）与官星壬相合，本为夫妻正配（丁酉、壬辰天合地合）；今丙（日主）介入丁、壬之间 → 断为插足他人家庭、妾命。
  2. 妾命何以转为正室？申辰拱水、壬可代子水，三合成正官局；夫妻宫（日支申）、子女宫（时支辰）因三合官局合为一体，故偏房转正，即「把丈夫夺了过来」。
  3. 丈夫带一女儿：女命以食神为女，辰中戊为女儿，壬辰同柱，申子辰合为一家 → 断「丈夫带一女儿，现一起过」。
- 结论：⑴富贵但婚姻质量不好，丈夫本是有家的人，插足其家庭后才结婚；⑵丈夫是「着装的人」；⑶丈夫有一女孩，现在一起过；⑷目前财运不错，但身体不好。
- 验证状态：书中已验证（整理者以实例印证「比肩争夫，偏房宠妾」及三合官局断法）

### C-B1-002 例二 · 乾造（短命，死于丁丑运甲戌年）
- 八字：乾造 乙卯 / 己卯 / 壬子 / 壬寅（1岁运；出生地：未载）
- 出处：盲派命理经典 · 整理者自序「试举几例」例二
- 涉及规则：
  1. [L8断事 > 寿夭与凶死 > 短命判据] 「身命逢刑反克时，短命夭寿」——先定短命，30岁前必死
  2. [L4口诀体系 > 看命口诀 > 岁君与大运配合 / L7大运流年] 「伤官最怕行官运」
  3. [L6神煞体系 > 羊刃 / L3冲合] 「阳刃怕冲惧合迎」——壬日坐子（壬之羊刃），忌冲忌合
  4. [L4口诀体系 > 断运篇] 「伤官之格，官杀重见，财旺身弱，混杂、冲刃，岁运又见，必死，活则伤残」——定死于甲戌年
- 推理链（盲师四句歌诀逐句推导）：
  1. 「身命逢刑反克时，短命夭寿」→ 先定此命短命，30岁之前必死。
  2. 「伤官最怕行官运」→ 排除/锁定行官运之限。
  3. 「阳刃怕冲惧合迎」→ 断死于丁丑运（丑合子，合动羊刃）。
  4. 「伤官之格，官杀重见，财旺身弱，混杂、冲刃，岁运又见，必死，活则伤残」→ 断死于甲戌年「官杀混杂之年」。另一种取法：寅中藏戊、干透己为官杀混杂；丁丑运丑为官，甲戌年戌为杀重见，直接找戊土杀星重见即可。
- 结论：此人已死；命中定短命，死于丁丑运甲戌年。
- 验证状态：书中已验证（盲师现场直断「此人已死」，整理者据四句歌诀复盘其推理）

### C-B1-003 例三 · 乾造（随母改嫁）
- 八字：乾造 庚戌 / 庚辰 / 甲申 / 甲子（1岁运；出生地：未载）
- 出处：盲派命理经典 · 整理者自序「试举几例」例三
- 涉及规则：
  1. [L4口诀体系 > 十神专论 > 偏官 > 年柱/月柱] 「年月偏官，随母改嫁」——年月双透庚（甲木之偏官/七杀）
  2. [L8断事 > 六亲 > 父母] 「月财逢库父早亡」——月支辰为财（土）之库
  3. [L3五行体系 > 地支三合 / L4口诀体系 > 宫星定位直断] 戌土偏财入辰墓，辰偏财合印星、合成印局生身（地支戌辰申子，申子辰三合水局为甲之印局）
  4. [L3五行体系 > 冲合刑害表] 「宫合」——宫位相合为断语成立之使用条件
- 推理链：
  1. 秘诀1「年月偏官，随母改嫁」：年、月两柱天干皆庚，为甲木之偏官（七杀），主随母改嫁之象。
  2. 秘诀2「月财逢库父早亡」：月支辰为财库，主父早亡。
  3. 秘诀3「宫合看」：戌土偏财入辰墓，辰（偏财）又合印星、合成印局（申子辰水局）生身 → 综合断随母嫁人。
  4. **关键使用条件**：上述 1、2 只是「象」，须得「宫合」才成立——宫合是 1、2 两条断语的使用条件；若无宫合（即无此宫位相合之结构），则 1、2 不成立，不能断随母改嫁。
- 结论：此造随母改嫁。
- 验证状态：书中已验证（整理者自述随盲师习艺后所断）

### C-B1-004 例四 · 坤造（克父克母、小妾命、一辈子无婚）
- 八字：坤造 丙辰 / 丙申 / 丙午 / 丙申（5岁逆运；出生地：未载）
- 出处：盲派命理经典 · 整理者自序「试举几例」例四
- 涉及规则：
  1. [L8断事 > 婚姻 > 婚期与克配] 「女命官星入库，冲库时成婚」——官星（水）入辰库
  2. [L4口诀体系 > 十神专论 > 比劫] 「姐妹刚强，填房之命」——天干四丙透出，比劫（姐妹）刚强
  3. [L8断事 > 婚姻 > 妾命填房二婚] 官星在辰库、辰在年支（年=长辈），象其人年长
  4. [L8断事 > 六亲 > 父母] 克父、克母
- 推理链：
  1. 女命以官星为夫。此造官星（水）藏于辰库，须待「冲库」（逢戌冲辰）方成婚。此造走逆运，今生走不到戌运 → 断「一辈子无婚」。
  2. 诀云「姐妹刚强，填房之命」：天干四个丙透出，比劫（姐妹）旺而刚强 → 断小妾、填房之命。
  3. 官星在辰库中，辰在年支；年柱主长辈、年岁大 → 断包养者为「老头」。
  4. 综合：官星入库又不逢冲、比劫刚强 → 断克父、克母，小妾命，一辈子无婚，被人（老头）包养。
- 结论：此造克父、克母，小妾命，一辈子无婚，被人包养，且包养者是个老头。
- 验证状态：书中已验证（整理者自述随盲师习艺后所断）
