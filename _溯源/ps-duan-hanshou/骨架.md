## 一句话主旨

**盲派把四柱当成一件有固定结构的器物来读**：干支配置本身即「先天垂象」（谁有、谁没有、谁被谁制住、谁被谁合走），

## 作者的核心命理主张

1. **不用格局论贵贱，用「象」断事**。诸书「格局是附于用神」（卷四开篇即言「格局是附于用神」），本书反其道：先看干支配置的垂象，再谈用忌。这是段派与子平格局派最根本的分界。
2. **六冲有七法，冲不必然凶**：冲凶 / 冲旺 / 冲动 / 冲开 / 冲出 / 冲去 / 冲破。同一个「冲」，咬到忌神是吉，咬到用神是凶；冲库是开，冲根是坏。
3. **六合只用三义：合留、合绊、合凶**；且**六合可以解三合**，「合了为没有了」——被合走的星在断事上等于不存在。
4. **「去忌神时反得忌喜」系列**：伤官去官格（官为忌，以伤官去官反得官）、比劫去财格、去印得权（印为忌，去印得官）、以禄当财 / 伤官当财。这是本书自成一格的取用逻辑。
5. **忌神三种制法**：弱忌要旺制、旺忌要弱制、略偏旺则平衡制；制化不当的应在哪一年，是「有错必纠」一章专门修正的对象。
6. **宾主 / 世应六层**：年月为宾、日时为主；大运为客、太岁**反客为主**——「晦太岁」是一切纠缠、官非、合伙破裂的共同机制。
7. **干支自合（天地合）改变意向**：丁亥 / 甲午 / 戊子 / 己亥 / 辛巳 / 壬午 / 癸巳 / 丙戌 / 壬戌 九组干支自合，自合则该柱「里外一体」，意向与单看干支不同。
8. **活论**：十神活、六亲活、宫位活——同一个字在不同柱、不同合冲关系下代表不同的人或事（「以禄当财」「时透七杀主聪明」）。

### 作者的断法风格

- **流派倾向**：**盲派**（郝金阳先生口传 → 段建业整理 → 易缘轩函授教学化）。与子平格局派、旺衰派三方均不同：不言格局贵贱，不以身强身弱为纲。

### 时代与流派局限

1. **口传体系 + 选择性记录**：大量断语的唯一依据是「郝先生断过某命、断准了」（如第八期「一个人拿着刚出生的羊羔的命考他」）。**只记断准的、不记断错的**，构成典型的**事后追认偏误**——本书不具备可伪证性，用其规则做预测时须显式标注「单源·低置信」。
2. **教学稿的低分辨率排版**：源资料为 DOC 转档 txt，**干支分行式排版 + 形近字错**（已定位 fix 76 行 / soft 16 行 / 残项 2 行）。凡命例四柱一律以 `_audit/源资料质量报告.md §3.5` 判正，**不得据未判正的原文直接取象**。
3. **女命旧语境**：第二十期「色性的看法」、第四十一期「绊禄桃花」等含贞操歧视与职业贵贱断语（源文用「淫贱」等字）。按任务卡：**一律降级为不采用**；婚姻不顺的实质内容改用中性语言表述。

### 未被证明的假设

4. **「配置 = 事实」的直连**：本书大量规则形如「卯辰穿 → 父母辰为母星、母位 → 母亲去世」（卷四例 14），**跳过从干支配置到人生事实的全部机制论证**。照抄会得到高度具体但不可验证的断语。
5. **宫位与六亲的固定对应**：年月日时 = 祖辈/父母兄弟/自己配偶/子女，虽在卷四给出，但同时又主张「活论六亲」，**两套口径未说明何时用哪套**，按配置任选一套几乎总能自圆其说。

### 方法的失效场景

6. **时辰不准即全盘失效**：**卷四明言「利用时辰断兄弟姐妹数」「头胎生男女判断」**，且大量断语依赖时柱（如「时透七杀主聪明」）。时辰错一柱，本书一半以上技法失效——使用前必须确认时柱来源。
7. **现代职业无取象**：职业取象库停在「军官/师长/医生/会计/口才/报社主编/区长」等前互联网时代岗位，对现代职业需外推，**外推部分本书无据**。
8. **从格/化格边界**：第二十二期专章承认「什么情况下会从、什么情况下以身弱看，比较难以分辨」，即作者自认此边界不可靠；凡涉从格断语须标注此项。

### 最强的反驳

9. **不可伪证 + 自认有错**：第十二期「A、有错必纠」中作者**自己修正了前面期次的错误**（含应期与制化原则）。这说明书中规则**存在版本差异**：同一条断法在第二期与第十二期可能不一致。反驳者可直接用作者自认的错误证明该体系的证伪成本无法收敛。
10. **断语颗粒度与可核性倒挂**：断得越细（具体到"母亲去世""赔钱 5 万元""94 年闹离婚"），越依赖已知结果反推，越无法用于未知命例。
