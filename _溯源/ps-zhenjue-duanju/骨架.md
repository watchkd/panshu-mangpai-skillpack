# 《命理真诀导读》骨架

> 任务卡：B1 ｜ 池B·段建业口诀 ｜ 源资料：《命理真诀导读.docx》｜ 内容简称 `ps` ｜ 目标技能 `ps-zhenjue-duanju`

## 一句话主旨

**断命以"病药"取用神为纲，但看身体与寿元另立"寿元星"一轨——用神只管行运好坏，寿元星才管生死；所有断语必须落到五行生克与冲合会刑穿之正理上，古诀口诀只是这套正理的浓缩表达。**

## 全书结构

本书是**段建业（笔名"卜文"）对宋英成等台湾命理家命例文章的"导读"**：主体是宋英成等人公开发表的命例（含「原解／宋先生分析」），段建业逐案写出「**卜文解评**」（43 处）或「**作者解评**」（33 处）——两者皆为段建业本人的评注体系，只是不同批次文章的落款不同。

| 部分 | 讲什么 | 与前一部分的关系 |
| --- | --- | --- |
| 理论纲领（第1–3章：算命三步曲／喜用神的研讨／八字的应期） | 建立"排演→测象→断事"框架、病药取用神、应期引动三大总纲 | 全书方法论基石，后 57 章皆是它的命例验证 |
| 命例实战（第4–60章） | 约 60 个主命例，按人生领域散落：六亲、婚姻、疾病、死亡、官讼、财赌、性情、居宅 | 逐案演示总纲，并**反复驳斥原解、给出替代推理链** |
| 命相谈奇（第30/32/38/41/59章等间插） | 江湖命师传奇（张燮堂、唐山仙、许天愚、范先生、郑清德、郝金阳）与骗术揭露 | 佐证"口诀不可轻传""命理有灵感成分"，也是本书"口诀"来源的交代 |

> **本书"口诀"的三种来源**：① 古书口诀引证（《滴天髓》《渊海子平》《三命通会》《穷通宝鉴》《继善篇》《碧渊赋》《五言独步》《四言独步》《五行生克赋》《千里马》《珞琭子消息赋》《渭泾论》《幽微赋》《明通赋》《相心赋》《造化元钥》等，全书引诀 80+ 处）；② 师传口诀（吾师郝金阳先生，如"甲生酉月身喜水润，乙生酉月用火攻""女命伤官无财印绶多，伤花克子罪难多"）；③ 段建业自拟断诀（如"制忌神时得忌喜""活木怕埋根之铁""火死于它最旺之年"）。

## 作者的核心命理主张

1. **用神自由心证论**：喜用神"真正的作用只是使命局的五行流畅而已"，不必拘泥扶抑定式；同一八字可"运气好而身体差"，故须把"行运吉凶"与"身体寿夭"分开看。
2. **寿元星独立于用神（本书最核心的技法独创）**：断生死不看用神，看**寿元星**；禄、印、食神、伤官、官杀皆可充当寿元星，选取原则是"维持生命存在的那个字"（如从财格以病神亥水作寿元星）。用神管吉凶顺逆，寿元星管生死存亡。
3. **五行各有死法，火最特殊**：火的生存靠木燃烧，**火多死于"木被焚尽而自灭"，即死于它最旺之年**，未必死于被克；木有"活木怕埋根之铁""死木不受水生"之别；水有"旺神冲衰衰神拔"。这是段建业反复用来自证、并据以驳斥宋先生"逢墓忌邀"的独门逻辑。
4. **从格判据："五阳从气不从势，五阴从势无情义"**——"气"指地支泄我者（内在自我），"势"指天干克耗我者（外在压力）；段建业据此判"假从／真从"，且强调从格一旦成立，**大运见比劫反凶**。
5. **六亲以十神转换论，子女星不取官杀而取伤食**：明确主张"当伤食星临子女宫时，就以伤食星当子女看"，反对以官杀为子女；并给出"伤官见财而有子，伤官无财子宫有死""时上伤官及空亡难为子息"等判据。
6. **神煞必须服从五行生克与六亲关系**："任何神煞都必须配合五行生克及六亲关系使用，否则很容易出偏差"；神煞只作"附合"，主断仍靠正理。
7. **"制忌神时得忌喜"**：局中某十神为忌神，当岁运把它制化时，反而得到该忌神所代表的东西（如财为忌，制去财反得财）——段建业称为"论命的一个重要原则"。
8. **信息同步而不言"克""妨"**：家人吉凶信息在同族命中相互反映，是"儿子的命反映父亲的死"，不是"儿子克死老子"；故为人论命**杜绝使用"克""妨"字样**。

## 结构主干（决定技能包归并方向）

**本书结构主干：混合型（口诀型为主干载体，断事命例为验证场景）**

- **判断依据**：全书 60 章中，第 1–3 章为理论纲领，第 4–60 章为命例断事，章名多为故事化标题（"痛失麟儿""第三者插足""伤官奇谭"…），并非按格局分章；**断法结论几乎全部以古诀／师传口诀＋五行正理给出**，符合任务卡"口诀类书"的定性。
- **归并方向**：任务卡硬约束"一个任务只产出一个技能包"，故不拆分。技能内部**按"断法路径"分层**（旺衰/从格 → 取用神 → 原神与寿元星 → 十神六亲 → 冲合会刑穿应期 → 断语），口诀作为每层的"出处与依据"随规则携带。

### 作者的断法风格

- **流派倾向**：综合派。以子平格局／旺衰为骨架，但明确"用神自由心证"；兼采盲派师传口诀（郝金阳）、六爻应期原理（"动而逢值逢合"）、部分神煞（取极少数）。
- **推理路径偏好**：`定旺衰/从格 → 取用神（病药）→ 找原神与寿元星 → 论十神六亲与宫位 → 用冲合会刑穿定应期 → 下断语`。
- **命例使用习惯**：以大量命例佐证；每案先照录他人（多为宋英成）原解，再**逐条指出"解释有误／不能成立／弯绕太大"**，随后给出自己的替代推理链——即用"**驳论**"来确立方法论。
- **对"先贤"的态度**：既引古诀作依据，又敢否定宋先生常用的"逢墓忌邀""冬至换年""冲羊刃入墓"等说法；对"师门秘诀"则屡屡声明"不可轻传、面授再讲"，留下断法缺口。

## 盲点与边界

### 时代与流派局限

- 成书语境为 **1980–90 年代台湾命理杂志**：大量断语依赖**当事人事后反馈**（如"事实上她真的…""据说…"），部分案例段建业直言"可能是命主告他的，而非算出来的"；官贵/武职/科举式价值观（"功名显达"）比重高，现代职业命理场景需重估。
- 全书是"导读"，主体正文（宋英成等）与评注（段建业）交错；**评注才是本书的方法论**，但评注本身也多次声明"师门口诀不可轻传、面授再讲"，关键链环被人为省略。

### 未被证明的假设

1. **寿元星的选取无统一算法**：禄、印、食神、伤官、官杀皆可作寿元星，选择依据是"哪个字在维持生命"，但如何排除其他候选，书中未给可操作判据，容易事后选定。
2. **"火旺无制焚木而亡"等五行死法**：是自然隐喻而非统计结论；同一"焚死"逻辑被用于不同八字时，力度与边界不清。
3. **原神决定论**：把"某星无原神"直接等价于"该亲必早逝"，未处理反例（书中有"同八字不同结果"的自认）。
4. **暗合/伏吟/神煞取象的宽严没有阈值**：什么程度算"动了""合了"，靠经验裁量。

### 方法的失效场景

- 段建业自己承认："**我们对命理的分析在许多内容上只能作到近似的推断，并没有绝对的论断**""同一时辰出生的人，不一定就会在…结婚"——即**不承诺确定性**。
- **无时辰（三柱）**时，子女宫、晚年、寿元星无从定位，全书断法基本失效。
- **子息、居宅环境、痣斑、身高长相**等断法，段建业明言"未必能在八字中显示""是从相学上看的"，即超出八字边界。
- **六亲死亡、桃花、婚姻破裂**等大批断法被作者刻意"保留"，书中只给结论不给推理，导致这些规则**不可复现**。
- 对**集体应灾**（唐山大地震）作者自认无法用命理解释。

### 最强的反驳

- 本书方法论的最大软肋是**事后解释（确认偏误）**：所有驳议都是在已经知道结局（某人死了、离了、坐牢了）之后反推五行理由，段建业批评宋先生"未讲出依据"，但他自己的替代解释同样是事后建构。
- 作者一边主张"五行正理""反对单看神煞"，一边又保留"师门秘诀"来解释关键案例（张燮堂、许天愚的"千里眼"功夫），**方法论自洽性受损**。
- "信息同步"论（不是丈夫克妻，是妻子的病在丈夫命中同步反映）无法证伪。
