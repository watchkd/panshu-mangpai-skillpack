## 一、为什么要有这个体检

断语出问题，多半不在「断得对不对」，而在**断得没法核对**。应期这一层最常见的三种硬伤，都是一查就能查出来的机械问题，不需要懂命理：

| 规则 | 查什么 | 为什么算硬伤 |
| --- | --- | --- |
| **R1** | 年份与干支年**同指却不合**（「2005 年乙酉年」这类写法） | 干支与公历年对不上，整条应期线跟着歪；读者拿万年历一翻就发现 |
| **R2** | 断语**落到「日」**（把应期写到具体某一日、初几应验） | 违仲裁 #20；「日」不是本门可断的一层，写出来等于把不可核对的东西说成结论 |
| **R3** | 提到「五年一交」却**未说明干段／支段并存** | 违 v1.7 起的交运口径（`命书体例.md` 六之二）；少了这一句，干段与支段的气象就混成一团 |

**脚本不管的事**：判断吉凶对错、规则是否适用——那是断法层的事。

## 二、纳入与排除口径（避免把原书实录当成本包错误）

| 类别 | 处理 | 理由 |
| --- | --- | --- |
| 断语文档（`批词`／`命书`／`体例`／`范例`／`话术`／`报告`） | **默认扫描，计入门禁** | 本包自己写的断语，标准须自持 |
| 原书命例库（`命例.md`、`案例集_*.md`、`命例库.md`、`命例索引.md`） | 扫到但**降级为原书记录提示**，不计门禁 | 书上本来就可能断到日，属「引原文实录」，照录不改书 |
| 生日／书上生时（含「生于」「乾造」「坤造」「例 123」「生日」等上下文） | **跳过** | 这是排盘输入，不是应期断语 |
| 月建区间写法（「卯月（三月五日—四月五日）」） | **跳过** | 这是节气换月边界，属历法不是应期 |
| 交运时刻（含「交入」「处暑」「起运」等历法词） | **跳过** | 纳音定日时，属历法计算；体例第 6 禁已列为例外，但须标「交运」 |
| `升级说明_*.md` | 跳过 | 版本说明文档，不是断语 |

## 五、怎么用

```bash
# 出门验收（断语文档，R1 > 0 即非零退出）
python tools/check_yingqi.py --strict

# 看明细
python tools/check_yingqi.py --verbose

# 全包巡检（含原书命例，结果只作提示）
python tools/check_yingqi.py --all --verbose

# 只查某个子包
python tools/check_yingqi.py --only 盘叔盲派/ps-zonglun

# 机读报告
python tools/check_yingqi.py --strict --json 应期体检.json
```

**门禁口径**：断语文档 R1／R2／R3 全 0 为准；`--all` 模式下的「原书记录提示」不设阈值，属留档。

## 六、与另两个体检器的分工

| 体检器 | 只管一件事 | 不管什么 |
| --- | --- | --- |
| `check_refs.py` | 引用**指得到吗** | 内容对不对 |
| `check_arb.py` | 裁决号**都对得上吗** | 裁决本身合不合理 |
| `check_yingqi.py` | 应期**自洽吗**（年份干支／不落日／交运并存） | 断得准不准 |

三者皆纯标准库、只读、不联网；三者都不判内容对错——内容对不对，归仲裁摘要与人。
