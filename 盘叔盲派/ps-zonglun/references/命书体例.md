# 命书体例（交付件规范）

> **本文件只管「怎么呈现」，不管「怎么断」。**
> 断法归 `ps-zonglun` 七层调度与二十八子技能；本文件规定命书长什么样、
> 哪几句话能进命书、哪些字一个都不许出现。
>
> 一句话分工：**`ps-zonglun` 出断语，本文件管排印，`tools/mingshu.py` 管落地。**

---

## 一、先分清两件东西：底稿 vs 命书

同一张盘，交付两种纸，读者与规矩完全不同：

| | 底稿／统一报告 | 命书 |
| --- | --- | --- |
| 读者 | 批者自存、要复核的来客 | 命主本人 |
| 内容 | 七层推演、分域断语、**规则编号／置信度／命例编号** | 只有判断与实事 |
| 编号 | 每条带（`MP-*`／`U-####`／块号） | **一个都不带** |
| 星级 | `★`～`★★★` 照录 | **一个都不带** |
| 形态 | Markdown／表格 | 纸墨 HTML，可打印 |
| 出现「规则集」「仲裁」「E1–E6」 | 可以 | **禁止** |

**这不是审美，是分寸。** 命主买的是「这件事会怎么样」，不是台账。
台账留底稿，命书只出判断——两件东西混在一起，命主读不懂，批者也说不清。

## 二、五档命书：先定档，再动笔

梁氏旧例分五档，盘叔这套沿用同一把尺子（档位定篇幅，不定深浅）：

| 档 | 范围 | 盘叔这套怎么落 |
| --- | --- | --- |
| **简批** | 一纸 | 百字上下，一句层次 + 三件实事（婚、财、业）。聊天里直接给，不出 HTML |
| **小批** | 现运 + 今年 | 一段原局定调 + 当前大运 + 今年应期。不出 HTML |
| **中批** | 五至十年 | 原局 + 层次 + 分域 + 近十年运程。**大运不逐运分述** |
| **大批** | 交批之年起三十年 | 原局 + 分域 + **逐运分述** + 流年举要。出 HTML |
| **细批** | 大批 ＋ 流月 ＋ 校准 | 多一层实证校准与附卷。**默认交付档**，出 HTML |

**规矩**：中批以下不出 HTML（一页纸排印反而不如对话里说清）；
大批、细批出 HTML；**细批是标准交付**，简批与小批只走对话。

## 三、细批命书的章节骨架（盲派七段 ＋ 附）

**先说清一件事**：盲派原典不出「命书」，出「命稿」——乾造起头、四柱直排、大运横排、
批语接排。原书里没有「六亲章」「财禄章」这种分章，是一路断下去。

本包的命书＝把命稿**规整化**：抬头照原书的排法，正文按盲派的推演次第分七段。
断法仍是 `ps-zonglun` 那套（日主之意 → 做功 → 层次 → 逐事 → 应期），
只是排成能读、能打印、能交付的样子。

> 原书实证：四柱「乾：庚乙癸庚／辰酉卯申」＋「大运：06 丙戌 16 丁亥」，
> 见《盲派中级命理学》；问答式批语见《命术秩闻·夏仲奇卜命遗例集》。
> 本包只取其「形」，断语出处一律是本包的七层调度。

| 节 | 名 | 谁写 | 硬要求 |
| --- | --- | --- | --- |
| 卷首 | **命稿抬头** | 工具 | 乾坤造起头，四柱干支**分两行横排**（天干一行、地支一行），大运按起运虚岁横排。**不加边框、不加底色、不标十神** |
| 卷首 | 一行小传 ＋ 怎么看这份命书 | 工具／批者 | 乾造、生年、起运虚岁；再看三句：不取用神、断语分寸、校准声明 |
| 一 | **命式** | 工具 | 四柱细目表（十神／藏干／纳音／本柱旬空）＋ 五行条 ＋ **关系表（刑冲合穿拱／天干合冲／干支暗合／禄刃）** ＋ 空亡两查 ＋ **空亡细判（位／根／击／值冲合）** ＋ 时辰边界。**一句断语都不许有** |
| 二 | **日主之意** | 批者 | 首句「此造『X』日主，生在『Y』月」；再说日主要合什么、日支要制什么、局中有无势。**只定「它想干什么」，不下吉凶** |
| 三 | **做功与层次** | 批者 | 正局／反局；功在几处、效率高低；贵贱属哪一路（贵／富／能手／劳碌）；官禄有无。**层次先于细节** |
| 四 | **逐事直断** | 批者 | 按事分小目（财禄／功名／婚姻／六亲／身命，按盘增减），**每事先断后据**。六亲不单立章，落到事里说 |
| 五 | **大运逐运** | 批者 | 逐运一段，首行标干支＋虚岁＋公历年。讲「这一步把做功方式改成了什么」，**不逐流年细推** |
| 六 | **流年举要** | 批者 | 只举关键年，**只定应期不断吉凶**；凑不齐条件者明写「只记结构」。细批须在此节末附**本年流月表**（工具出，`--liuyue`），正文至少用到其中两三个月；大批不附 |
| 七 | **结语** | 批者 | 三条，是全篇的骨，不是摘要——**命主只读这三条也该知道该干什么** |
| 附 | **说明** | 批者 | 时柱校核、校准记录、存疑项、边界与免责；「不准」的余地写在这里 |

> 编号由 `tools/mingshu.py` 自动排：命式＝一，正文自二起，附节不编号。
> 批词里不要自己写编号，写了会被剥掉重排。

**与子平命书的分别**：子平按「六亲／财／官／印」分章，盲派按「日主之意 → 做功」推进。
七段里的「逐事直断」是**按事**分（婚、财、功名、身命），不是按十神分——
因为盲派断的是「这个人这一件事」，不是「这个十神怎么样」。

## 四、直断式笔法（每一节里怎么落笔）

盲派批命有两种口吻：段建业案例集的**直断式**（不设问，一段推进），
夏仲奇、邢铭芬的**问答式**（「为何十六岁丧母？」逐问逐答）。本包取**直断式**。

一段断语的标准骨架，三步：

```
断语 → 结构依据 → 分寸
```

**「逐事直断」每一事，都要先落一句可证伪的实断再讲依据**（v1.5）。实断是过去时、
能当场对上的那种（「二十几岁到三十出头那几年，钱进来又出去」「父辈早年起落，
不在一个行当里做久」），不是「您这命财星有根」这种谁都能套的话。

道理很简单：**命主读完只能说「有道理」，与读完之后心里一惊，是两种东西。**
前者是说明书，后者才是批命。段建业原书批语即如此——先报事实，再讲结构。

> 分寸仍要守：实断只断**结构上站得住的形状**（钱留不住、婚不早、父缘薄），
> 不断具体数目、具体人名、具体年份的死口。灵不灵另说，先说得住。

- **断语**：第一句就下断，不铺陈、不引书诀。原书是「此造满盘是金……实际是中央银行行长」，
  不是「观贵造之格局，似有可论之处」。
- **结构依据**：本盘哪个字、与谁、发生什么作用（刑冲合穿墓、宾主、做功）。
  **只说规矩，不说编号**——编号是底稿的事。
- **分寸**：三档取一（见第五节）。

起句用**「此造」「看这一盘」「照结构看」**，不用「贵造」「您这命」；
不引经文原句（引诀是问答式的写法，直断式不引）；一段只说一件事，说完就断，不绕。

**示例**（取自 `范例/批词_甲子乙亥庚戌癸未.md`）：

> 财在宾位（年月），要合到主位才算到手。本盘乙合日主，算合到了；甲在年干，
> 隔着月柱，只算看得见、够不着。

**「命式」是全篇的地基**：它不带断语，只把事实摆齐——四柱十神、藏干、纳音、
两处旬空、五行分布、时辰边界。摆得齐，后面每句断语才站得住；摆不齐就开始下断，那是猜。

**空亡细判是这一节的地基**（v1.4 起三判，v1.5 加「位」为四判）。查完「哪一支空」，还要摆出四件事实：

| 判项 | 摆什么 | 批者拿它做什么 |
| --- | --- | --- |
| **位** | 落于日、时（主位）或年、月（宾位） | **先看这一层**：同一字空在主位为忌、空在宾位不忌。主位落空是「自身根基虚」，宾位落空只是「外物不实」 |
| 根 | 有根（同气相扶／藏干透干）或无根 | 有根之空待填、无根之空近真空——这是「空」的两种性质，不能一概而论 |
| 击 | 有无冲穿刑来击（含自刑） | 钟不击不响。受击之空与不受击之空，应事不同 |
| 值／冲／合 | 岁运走到／冲／合此支的年份 | 命书只标**本轮的最近一次**，全量留底稿；**不作应期断**，断应期仍走应期四律 |

> **根与击须合看，不得只取其一。** 一个支可以既得同气、又受刑穿（如戌得未同气、又受未刑）。
> 这种情形只能判「**根在有损**」，不能判「有根」了事——只取扶不取刑，是全篇最容易被同行抓住的一处。

> **红线**：细判只摆事实，**「金空则鸣、火空则发」这类取象一个字都不进命式**。
> 取象归 `ps-shensha`／`ps-duan-mianshou`，由批者在正文里断，不在命式里断。
> `mingshu.py` 自检已加拦截：命式里出现「鸣」「朽」「填实」即 FAIL。

## 五、分寸三档（写进句子，不写标签）

| 档 | 结构条件 | 落笔用词 |
| --- | --- | --- |
| 确断 | 三路以上独立结构同向（子女两路） | 「照结构看是……」「这盘是……」 |
| 倾向 | 两路同向，或一路极硬 | 「多半是……」「大体上……，但有一处要打折」 |
| 存疑 | 单路、或引用条件只部分成立 | 「这一步要留意……」「看不准的是……」 |

**禁止**：「一定」「必然」「肯定」「铁定」「绝无」。
本门的线是**七成应验即合理合宜**，写成铁口，等于自己把话说死。

## 六、行文六禁（每一本都查）

1. **禁套语**。「金寒水冷」「火炎土燥」「格局清纯、福泽绵长」——这类句子谁都能套，
   等于没断。要「落实」：写到婚、财、子、疾、业的字面上去。
2. **禁扶抑口气**。本门不取用神、不看旺衰喜忌，故不许出现
   「日主偏弱，喜印比帮身」「用神得地」「身弱不能托财官」这类句子。
   日主强弱只有一个用处——**能不能承载财官**，写成这一句就够。
3. **禁把大运当缩版八字批**，禁把流年当小一号的大运批。
   大运讲的是「这一步把做功方式改成了什么」，流年只讲「哪一年被引动」。
4. **禁把断语塞进表里**。表格只放结构（干支、虚岁、公历年、旬空），
   吉凶一律进正文。表里出现「吉」「凶」「平」三个字，就是偷懒。
5. **禁取象不带关**（v1.5）。凡用「金空则鸣」「火空则发」「木空则朽」一类口诀，
   必须写明**过了哪几关**：用神／有根／逢击三关，金空另加「成器」关。
   缺关即降格断——「金空则鸣，主才艺」一句不带关，就是把口诀当格用。
   四关细则见 `ps-shensha` 空亡条；木、土二空没有吉的响法，不得凑吉。
6. **禁应期落到日**（v1.8，对应仲裁 #20）。段派应期只到**年、月**，夏派到**月**，**均不到日**；
   凡把应期写到具体某一日（几号见事、初几应验），读者无从核对，也把「日」这一层说成了可断之物。
   两处例外，须显式标来源：① **交运时刻**（纳音定日时，属历法计算，不是应期）；②
   **原书实录**（`ps-anli-ku` 扫描集原文明写某日者，照录并标「书载」）。
   自查：`python tools/check_yingqi.py`（规则 R2）。

另有一条心态线：**命书末尾要留「不准」的余地**（写在附言），不得通篇铁口。

## 六之二、交运（v1.7，与流月同时用）

大运不是一步到位，是**五年一交**：前五年天干主事、后五年地支主事（`ps-tiwei-jichu` 表 1-3 补充）。
交运时刻**按生年纳音定**，不按三除之日：

| 年命纳音 | 交运时刻 |
| --- | --- |
| 火命 | 清明前三天 午时 |
| 土命 | 芒种后九天 辰时 |
| 金命 | 处暑当日 申时 |
| 木命 | 大寒当日 寅时 |
| 水命 | 冬至前三天 亥时 |

工具（`paipan.py`）已算：起运年为「出生年 ＋ 起运虚岁 − 1」，此后每五年一次，落在哪个流月就标在哪个流月，
流月表下另印一行「交运基准／起运年／本年交运／下一次」。

**写批词的三条纪律：**

1. **一步运要断成两截，不许笼统说「这一步好」。** 干段主事前、支段接手后，是两种气象；
   两者混说，命主对不上号，也把「五年分段」这一层丢掉了。
2. **支段未到，运支只在字上。** 流月表写「运支卯（干段未到）」，就不许在正文里拿它当「卯已到」用；
   写了「同运支」，才算支已主事。
3. **交运本身不论吉凶。** 交运月只标换气，吉凶看运与命局。交运年写「交入某运、名分何事先到」，
   **不写「交运必有大变」**——那是拿时辰吓人。

**并存期三条（v1.8）：** 交运时刻落在某月月中，旧运余气与新运之字会同时在盘上，这一段叫**并存期**。

1. **并存期多长，以交运时刻所在的节气月为界，不另立日数。** 金命交运在处暑当日申时，申月未过，
   则自交运时刻起、至**白露交节**止，这一段属并存期；界限就是那个月的「节」，节一到，旧运即退。
   写在批词里用「旧运余气至某月（某节）止」，**不写具体哪一天起哪一天止**——应期不到日，
   唯一的日级时点只有交运时刻本身（见六之一·纪律 6）。
2. **并存期内的事，记旧运的账。** 交运后节未到，见财聚、见合用，仍判旧运那一段的话
   （例：干段末交入支段，白露前见合，写「名分先到」，不写「局已成」）；节过之后同一事才记新运。
   唯一例外：**事在交运时刻之后，且由新运那一字直接引动**（当月即与运支作合起局），方可记新运。
3. **禁「交接」「过渡」一类含糊词，写成可核的时点句。** 写「2028 年八月二十二日申时交运，卯接手」，
   不写「己卯运交接前后」「卯土过渡期」。一句里须钉死三样：**哪一年、哪一月、哪个时辰起，
   哪一段由谁接手**；看不出「第几运、哪段起」的交运句，等于没写。
   `mingshu.py` 的交运行必印「交第 N 运某干支（某段起）」，就是这三样的机检版。

> 木命交运在**大寒**（次年一月，尚在立春前），归**上一年**那一轮；水命在冬至（十二月），
> 归本年。这一处错一格，虚岁就错一岁，整条应期线跟着歪。

## 七、版面规范（`tools/mingshu.py` 已实现，改稿时照此核）

| 项 | 规格 |
| --- | --- |
| 纸 | 宣纸底 `#fbf9f3`，页面底 `#e8e4da`，纸边一道朱红顶线 6px |
| 字 | 宋体族；正文 15.5px／行高 1.9；段首缩进两字，两端对齐 |

| 章节 | 序号用中文数字，朱红小字；节题下一条细线 |
| 表 | 细线表，表头浅底，数值居中、说明左对齐 |
| 大运 | 抬头处横排一行（虚岁＋干支，当前运右上角朱红「今」）；正文内每运一个小目：左侧竖线，首行干支＋虚岁＋年份 |
| 强调 | 批词里写 `==这一句==` → 朱红加粗。**整本不超过十处**，多了等于没强调 |
| 页尾 | 「命书终」＋ 批写年月 ＋ 独立推广块（与正文分隔，明标「不是命理判断」）。推广块的固定内容、两张二维码、三档降级见 `推广尾注.md`；`--no-promo` 可整块去掉 |
| 打印 | A4，页边 22mm×18mm，无阴影，折叠表自动展开 |

## 八、批词怎么写（工具吃什么）

`tools/mingshu.py` 吃一份 Markdown 批词，按 `##` 切节：

```markdown
## 二、日主之意
此造庚金日主，生在亥月……（日主要合什么、日支要制什么，只断意向下吉凶）

## 三、做功与层次
正局。做功只一处：乙庚合……（功几处、效率、贵贱属哪一路）

## 四、逐事直断
### 财禄
财在宾位（年月），要合到主位才算到手……
### 功名
```

| 占位符 | 出什么 |
| --- | --- |
| `{{命式}}` | 四柱表 |

| # | 查什么 | 怎么查 |
| --- | --- | --- |
| 1 | 零工程标记 | `mingshu.py --lint` 必须通过（无 `MP-*`、`U-####`、`★`、置信度、E 级、仲裁号、块号） |
| 2 | 七段齐 | 命式／日主之意／做功与层次／逐事直断／大运逐运／流年举要／结语（附：说明），缺一节要说明为什么缺 |
| 3 | 命式无断语 | 逐条看：每条只讲「有什么」，不讲「所以怎样」；关系表与空亡四判只摆事实，轻重一律留给正文 |
| 4 | 断语落五件实事 | 婚、财、子、疾、业至少各有一句落地；一句都不落地＝没断。每事开头须有一句过去时实断（能当场对上），只有结构描述＝说明书 |
| 5 | 分寸对了 | 无「一定／必然／肯定」；存疑项明写存疑 |
| 6 | 四柱与排盘一致 | 命书里的四柱、起运虚岁、大运干支，须与 `pan.json` 逐字对得上（改了批词忘改表最常见） |

| 8 | 档位自洽 | 自称「细批」必须附流月（`--liuyue` 出表，且正文第六节要用到它）；板式与自称不符，`mingshu.py` 会在出书时提示 |

## 十一、与「统一报告」的分工

`ps-zonglun` 的统一报告（`【命局层次】【分域断语】【命例佐证】【应期推算】【多派互证】【存疑声明】`）
**不是命书**，它是批者底稿与复核件：

- 报告：带编号、带星级、带命例 U-####，供复核与自存；
- 命书：零编号、零星级，只给命主看判断。

**两件东西可以同时交，但不能混成一件。** 来客要「凭什么这么断」，
给他报告；来客要「我这一生怎么样」，给他命书。

## 十二、边界

- 本文件只约束**呈现**。断法、取象、仲裁、层级判断，一律以 `ps-zonglun` 与各子技能为准；
  两边若有冲突，**断法优先**——排印不得为了好看改动断语。
- 命书里涉及医疗、法律、投资的部分，只作结构倾向，附言须写免责边界。
- 寿元、牢狱、重病三类高风险断语：**概率化措辞**，只判「这一步要留意什么」，
  不出确定年份、不出确定结论。
- 性别未注者，坤造专章断语不代入，页首标明「性别未注，只作通用层」。
