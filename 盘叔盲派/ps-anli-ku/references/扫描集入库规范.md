## 一、环境（一次性，约两分钟）

```bash
python -m pip install pymupdf  -i https://mirrors.aliyun.com/pypi/simple/
python -m pip install lunardate -i https://mirrors.aliyun.com/pypi/simple/
```

- **PyMuPDF**：栅格化主力。MuPDF 内核，二值压缩格式一网打尽。
- **lunardate**：农历换算。看着可选，实际必装——**这批书的日期是农历**（见第二节）。

验证：

```bash
python tools/pdf_render.py 书.pdf          # 体检：页数、每页图型
python tools/pdf_render.py 书.pdf -o 页图/ --pages 14-25 --dpi 160
```

> 不许一上来就 OCR。先出图，肉眼或视觉模型确认这一页**是命例页**，再识字。
> 把口诀页当命例页抄，抄完库里全是歌诀——v1.6 就在《盲人铁口断》上差点犯这个错。

### 三条路，按可用性排

| 路 | 做法 | 覆盖 | 备注 |
| --- | --- | --- | --- |
| **甲（推荐）** | PyMuPDF 渲染 PNG | JBIG2／CCITT／JPEG2000／JPEG 全 | `tools/pdf_render.py` |
| 乙（零依赖） | CCITT 流包成 TIFF 交 ffmpeg | 仅 CCITT 页 | 已实测可读；JBIG2 不行 |
| 丙 | `extract_scan_pages.py` 直切 JPEG 流 | 仅 JPEG 页 | 无需任何依赖 |

乙的做法：PDF 里 `DecodeParms << /K -1 /Columns W /Rows H >>` 的 CCITT 流，
按 1 位、G4、Photometric=0 拼一个最小 TIFF 头（11 个 IFD 条目），
`ffmpeg -i x.tif x.png` 即出图。段氏理象学 266 页即此类。

## 二、**这批书的日期是农历**——先核日期，再读断语

《盲派批命案例集》第一单元凡给出生日的 8 例：

- 按**公历**排，**8 例全不合**；
- 按**农历**排，**6 例四柱全合（含时柱）**，另 1 例仅年柱不合（明显刊误），1 例三柱不合。

即：**书上写「1958 年 12 月 20 日午时」，指的是农历腊月二十，不是公历 12 月 20 日。**
当公历排，年柱月柱全错，后面每一处应期都跟着歪。

所以入库顺序固定为：**渲染 → 读四柱与日期 → `verify_case.py` 核 → 才读断语**。

```bash
python tools/verify_case.py --pillars 丙申 辛丑 戊戌 甲寅 --date 1956-12-26 --time 寅时
python tools/verify_case.py --pillars 戊午 乙丑 庚戌 壬午 --date 1958-12-20 --time 午时
python tools/verify_case.py --pillars 戊午 乙丑 庚戌 壬午 --resolve      # 不给日期，反查
```

核出三种结果，写法各不相同：

| 结果 | 判据 | 入库怎么写 |
| --- | --- | --- |
| **合** | 四柱全合 | 直接记公历换算日 |
| **书柱疑误** | 只差一柱，余柱全合 | 记「书柱为准，器算作 X」，标疑误；**不改书** |
| **存疑** | 两柱以上冲突 | 只记书柱与日期，标「存疑，用前先定柱」 |

**为什么不改书**：断语是照书的柱写的。改了柱，断语就悬空——那就成了「我重排一遍再自己批」，
不是入库。书错是书的事，库里要留下这个错，别人才知道哪里可疑。

## 二、能进的那两本，是什么货

**《盲人铁口断》是口诀速查表手册，不是命例集。** 目录通篇是
「干支十神速查表」「地支刑冲穿绝合速查表」「财运算命应验断语」「七柱直断篇」…
182 页里命例极少，价值在**表**而不在**例**。

所以别把它的页数当成「263 例」的来源——那是另一本。入库前先看一眼目录，
省得把表当例抄，抄完发现库里全是口诀，一条命例也没有。

## 三、入库长什么样（schema）

命例一条一个记录，字段固定，缺项写「未载」，不许留空、不许猜：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 编号 | 是 | `S-GD-###`（高德臣案例集）／`S-DS-###`（段氏理象学）／`S-####`（其余扫描件）；既有 `U-####` 留给更早入库、未标来源的金标 |
| 造 | 是 | 乾造／坤造；书中未标则写「未标」 |
| 四柱 | 是 | 年月日时四组干支；**过形近字校正**（见下） |
| 出处 | 是 | 书名＋原书页码＋本次页图序号，三者缺一不可（页码与页图序号常差几页，两个都记） |
| 断语 | 是 | **要点＋短引**：结构依据与原书断法照实写，关键句可短引（一句为限），长段压缩成要点，并标页码——本库是索引与校验层，不作原书替代品；认不准的字用「□」占位，不许凭上下文补 |
| 取象链 | 否 | 原书若给出推理（如「火金相克主声音＋金空则鸣＋水润金」），拆成短句列出 |
| 归口 | 否 | 该例可佐证哪条规则（规则编号），查不到就空着 |
| 可用度 | 是 | 高／中／低——依据是「批语是否给出结构依据」，只给结论的记低 |

**形近字校正**（仲裁摘要 §六，逐字过）：巳／己／已、戌／戍、午／牛、未／末、
酉／西、卯／印。校正不了的按孤证处理，**不得**按上下文硬猜成某个干支——
一个干支猜错，整条命例的断法依据就废了。

## 四、分批与验收

- **分批**：一批 ≤ 20 例，抽完一批先对四柱做交叉核（与本库既有 `U-####` 撞车的，
  标「另见」不新建）。撞车多说明这本已被别处采过，先停手核来源。
- **验收三查**（v1.7 加第 0 查）：

  0. **日期历法先定**：有生日的必过 `verify_case.py`。按公历全不合、按农历合，
     即为农历本——一本之内历法只有一种，定了就在文件头写明。

  1. **干支合法**：每组干支必在六十甲子内（`paipan.py --pillars` 会拦形近字与非法干支）。
  2. **页码对得上**：随机抽 3 例回原页图核对，错一例即整批返工。
  3. **断语不改**：抽查 5 例，逐字比对原文，凡有润色即打回——**入库是存档，不是重写**。
- **不许做的**：不得据 OCR 残缺自行补全断语；不得把「书中推测」写成「书中明载」；
  不得把别派的断法混进段派命例的取象链。
