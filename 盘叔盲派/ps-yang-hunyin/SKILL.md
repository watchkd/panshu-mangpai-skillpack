## 核心判断

一句话：**先锁夫妻宫（日支），再用"星坐之字与夫妻宫有没有发生关系"筛出夫妻星，然后看星与宫的关系定离不离，取用神定助力拖累，比劫定出轨，最后落应期。**

主播原话（00:50、02:30、07:00）：

> "看婚姻第一个要素…永远离不开那个叫夫妻宫的东西，也就是你坐下这个字。"
> "和夫妻宫产生关系的财和官，才是你的另一半，才是夫妻星，否则不是，我们就按桃花来论。"
> "婚姻要稳定只有一种情况——就合进来的，它是最稳定的…大家记住一定是六合。"

## 怎么做

### 第一步 锁夫妻宫

日支即夫妻宫。全篇一切判断都以它为中心；日支被穿、被冲、被刑、被合，各有所指，见第三、五、八步。

### 第二步 取夫妻星（四个入口，按序尝试）

**入口 A｜坐支通关（主入口）**：某财或某官，其**坐下之字**与夫妻宫构成刑、冲、合、害（穿）、生任一关系，该财官即成夫妻星。一柱一体看：天干、地支、以及地支所藏之干都属于这一个人（36:10 "请看一柱，一柱都是这个人"）。

**入口 B｜天干五合**：星与日主天干五合，可直接定夫妻星（03:40 "天干五合也可以直接定夫妻星"）。但**天干定的是"会结婚"，地支定的是"能不能一婚到头"**——合而无地支关系者，结得成、离得掉（03:50–05:10）。

**入口 C｜家里的财官**：夫妻宫（日支）自己所带之财官，**即使不与夫妻宫发生关系，也直接定为另一半**（08:20–08:40 "家里的财官，我们直接定夫妻星，哪怕他不跟夫妻宫相…也可以定另一半"）。

**入口 D｜劫财兜底**：财官皆不满足 A–C 时，取**劫财**为配偶（29:00 "他这个八字就是以劫财来看另一半"）。此类结构必离，且配偶不老实、易在钱上损命主，见第五、八步。

**不合格者**：财官存在但过不了 A–C 的，一律降为**桃花**——"谈了个恋爱就没了，不会跟你结婚"（02:40、27:20）。**这是本法最容易被跳过的关口，跳过就会把桃花断成配偶。**

### 第三步 断离不离（稳定性裁断）

以"夫妻星与夫妻宫"的关系逐项对表，**一票即断，不必凑够几条**：

| 星与宫的关系 | 判 | 依据 |
|---|---|---|
| **六合**（天上地下双合最佳；仅地支六合亦可） | 稳定，不易离 | 07:00 "一定是六合" |
| 三合、半合 | 属"合进来"，仍主结合，但稳定度弱于六合，须再查宫是否另有冲穿 | 20:20 "六合、三合、半合都是合" |
| **绝** | 会结婚，但第一段必离 | 04:10–05:10 |
| **冲**（星冲进宫） | 会结婚，必离——"刑冲交战离婚命" | 05:50–06:00 |
| **穿／害**（同一义） | 必离 | 06:10 |
| **生**（星生宫） | 必离，主短暂婚姻 | 06:30 |
| **刑** | 不稳定，容易离 | 06:40 |

补充三类必离结构：
1. **夫妻宫伏吟**（同一字重现，如日支之字跑到月上）→ 离婚（34:00–34:40）。
2. **一星合两宫**：一个夫妻星同时合住两个宫（例：星为酉，年月两丑皆来合）→ 伴侣在外另有人（46:40）。
3. **多宫多亲**：夫妻宫既穿夫妻星、又另有一字合夫妻星（同时克又同时合）→ 离婚病（34:40–35:00）。

### 第四步 判助力还是拖累（必取用神）

**必须先取用神**，再拿夫妻星与夫妻宫的喜忌对表（08:50 "取用神，这是第一步"）。四象限：

| 宫 | 星 | 判 | 话术 |
|---|---|---|---|
| 用 | 用 | 配偶帮身、层次高 | 星在年、天地一气、又为用 → 可断"靠这门婚姻起家""配偶身家到某量级"（10:20–11:10） |
| 用 | 忌 | 拖累较轻，坏不到根上 | 13:00 "夫妻宫为用、夫妻星为忌，综合一下，拖累没那么明显" |
| 忌 | 忌 | **拖累最重**，且忌星合入宫者尤重 | 13:20 "夫妻宫夫妻星全为忌，两个人一合，保险（保）没了" |
| 忌 | 用 | 中平偏拖累 | 本场未单列，按上格降一级处理，须标"本法未明示" |

用神判定要连"用神有没有力"一起说：**用神在年、天地一气**是本场给出的"高层次"判据，只讲喜忌不讲力量，会把话说过头。

### 第五步 断出轨／背叛（四条路径，逐条筛）

**路径 1｜比劫同宫**：夫妻宫**藏比劫**，且夫妻星**也藏比劫**（或星与比劫同柱）→ 必出轨（15:00–16:40）。**单条不立**：只见夫妻宫藏比劫，不断出轨（15:10 "夫妻宫藏比劫，不一定对方就一定出轨"）。

**路径 2｜暗合**：与夫妻宫相贴之字构成暗合（本场明示：寅丑、卯申；位置不限月支、时支）→ 伴侣不老实、要出轨（17:00–18:10）。

**路径 3｜比劫暗合入宫**：暗合进来的若是**比劫**→ **100% 出轨**（18:20–18:50）。非比劫的暗合只是"不老实"，不可拔高成 100%。

**路径 4｜比劫合入宫**：比劫以六合、三合、半合进入夫妻宫 → 100% 出轨，**且主离婚**。细分：
- 一般比劫合宫 → 出轨＋离婚；
- **劫财**合宫（尤其劫财为忌）→ 离婚方式不体面：**卷钱跑路**，不分产、不协议（20:30–21:30）；婚内则表现为资产转移、骗投资、骗贷款，命主在钱上大损（31:00–31:30）。

**另一条旁证**：夫妻星**自身与比劫同坐**（星里藏比劫）→ 配偶不老实（16:20、40:40–41:00）。
**再一条**：一星合两宫 → 配偶在外找小三（见第三步补充 2）。

### 第六步 落应期（结婚年 / 离婚年）

**婚期有两条路，先看夫妻宫有没有六合**：

1. **宫有六合 → 取"合宫之字"到位的流年**，在其**试婚年龄段**内即婚（23:10–24:00）。例：夫妻宫为子、有子丑合 → 逢丑年（牛年）成婚。
   - **副作用必须一并说**：此类人每隔十二年、同一个字再来时必犯桃花——至少精神层面心动，男性多难自持，女性多为精神出轨（24:30–25:40）。**此为结构副作用，不是"必然肉体出轨"，不可夸大。**
2. **通则 → 取"夫妻星到位"之年**：星是哪一字，该字流年即婚，同样限在试婚年龄段内（44:10–45:10 "不管什么类型的八字，找对夫妻星，在他夫妻星到的这一年，他就会结婚"）。
3. **大运过滤（前置否决）**：若原局结构使婚姻无从发动（如女命食伤极旺），须先看大运是否解掉障碍，障碍不解，流年到位也结不成（55:10–56:00 例：食伤旺者须待印运制食伤，方有婚；亥来合夫妻宫、丑年到位而成）。

**离婚期**：

1. **口诀：男怕劫财，女怕伤官**（35:20–35:40）。
2. **女命**：**伤官同时坏掉夫妻宫与夫妻星**的那一年即离婚年——伤官冲宫、又合（或合走）星，双坏同现（36:50–37:50）。只说"伤官见官"不足，**必须落到"同时坏宫与星"**。
3. **男命**：同法换成劫财坏宫星。
4. **引动来源**：流年干支、或大运换运引动（合入宫之比劫被引发、夫妻宫被冲穿之运）。

**应期纪律**：年份与干支必须对得上；断到年，不断到日。

### 第七步 断段数与"好婚姻"标准

1. **段数**：数夫妻星之数（几字合格即几段），配合"合宫之字"数（例：年月两丑同合酉，一星两宫，则伴侣另有其人，不是两段婚）。**只可断"多、留不住、不止一段"，不可报具体次数。**主播自己在同场讲出轨时也自我约束："不是百分百，咱就不要乱断"（19:40–19:50）。
2. **好婚姻的定义**（本派口径极窄）：**不离婚即好婚姻**。吵架、形同陌路、伴侣出轨、无感情，均不计（58:20–59:10）。给客人下"婚姻好不好"的结论时，先声明这一标准，否则必与客人预期冲突。

### 第八步 三类特殊结构（单点补充）

**穿（害）**：主**双克**——既克星所在的六亲，又克被穿之宫位的六亲；**与喜忌无关**，不看用神（50:50–51:30）。例：酉戌穿，酉为夫在月上，戌在时支为子女宫 → 克夫＋克子女，且时支所藏食伤被坏 → 生女有损。带穿之造，六亲多少都带伤，不宜说"身体都好"。

**三刑入夫妻宫**（寅巳申、丑戌未一类）：婚后痛苦，且**克配偶**——刑到财星克妻、刑到官星克夫；男命官杀相刑易入官灾（59:50–60:40）。

**食伤／比劫失衡**：
- **女命食伤旺而无印制**：人挑、主见强、克官杀，**很难结婚**，常晚婚至极（52:10–53:50）；命中仍可有婚，但多配**二婚**之夫（53:50–54:20）。应期见第六步第 3 条。
- **男命比劫旺而不见财**：同样难婚；看上的对象总有人来抢（56:50–57:40）。

### 第九步 化解与建议（有则说，无则不说）

1. **降格择偶**：结构必离者，找**离过婚**的对象反而稳定；找初婚者"包离"（29:50–30:10；54:10）。
2. **宫星双忌者，劝不结**：已婚者劝"别离"、已离者劝"别再找"——再找仍是同一格局（14:00–14:20、43:20–43:40）。
3. **劫财合宫者防财**：不要把财权交给对方，合作、投资、贷款一律设防（22:30、31:00–31:30）。
4. **不宜生某一性别**：穿坏子女宫且所藏食伤被坏者，可提示生育方向的风险（48:20–49:30）。

## 判断标准

**做对了会看到**：五问齐备；先过"坐支通关"再定星，桃花与配偶分得清；离婚判据能指到具体是绝、冲、穿、生、刑中的哪一条；助力拖累先取用神再下结论；出轨的判据能说清是宫藏比劫、暗合、比劫暗合、还是比劫合宫，四者层级不同；应期落到具体年与干支，且与已发生的事实对得上。

**做错了会看到**：拿财官直接当配偶、不问坐支（本法第一错）；只凭夫妻宫藏比劫就断出轨（第二错）；把"暗合"一律说成 100%（第三错，须是比劫暗合）；用"夫妻宫受冲"一条断晚婚或断当年成婚而不辨其余；离婚只报"伤官见官"而不落到"同时坏宫与星"；段数报出具体数字；把"好婚姻＝不离婚"这条窄标准藏起来不说，直接说人家婚姻"很好"。

## 什么时候不该用它

1. **时辰未校正，整套失效。** 本派全部判据都压在日支（夫妻宫）、坐支与藏干上，时辰错一位，星宫关系全变。须先用兄弟姊妹数、已发生的婚期、六亲经历倒推校时。
2. **不看旺衰即下断，会漏掉第四步与第八步。** 本法与夏派相反，**必须**取用神；凡不愿取用神者，助力拖累与食伤比劫失衡两项不得输出。
3. **不得与夏派混用取星与用神。** 两派对"女命以何为夫"直接对立（夏派女以官为夫、无官取年支财；本派财官皆是另一半）。混用的结果一定是自相矛盾。
4. **段数、出轨与否，不得给绝对数或绝对结论。** 主播原话已自我设限："不是百分百，百分百有问题的，这个咱就不要乱断"（19:40–19:50）。出轨可断"结构性必出轨"（比劫同宫、比劫合宫、比劫暗合入宫三类），其余只说"不老实、易有外情"。
5. **六合入宫者的"每十二年犯桃花"，只到精神层面。** 不可外推为必然发生性关系（24:50–25:20）。
6. **暗合清单只有两对。** 本场明示**寅丑、卯申**。其余组合（如卯戌、巳亥、午亥等）本场未列判据，不得径行套用；遇需要时标"本法未明示"。
